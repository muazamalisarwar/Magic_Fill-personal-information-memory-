System Architecture

How Magic Fill Works: 3-Tier Pipeline

Engineered with privacy isolation, sub-second latency, and zero dependency on external tracking services.

Tier 1 • Ingestion

Intelligent Attribute Extraction

Users upload PDFs, Word resumes, or ID scans. The zero-retention extraction engine extracts names, dates, degrees, roles, and skills into clean JSON schemas.

POST /api/extract • 0.4s
Tier 2 • Storage

Encrypted Memory Vault

Structured into categorized partitions: Personal Info, Education, Multi-Role Experiences, Custom Q&As, and Documents. Fully portable with instant JSON vault backup.

AES-256 Partitioned Vault
Tier 3 • Execution

Manifest V3 Extension Engine

Lightweight DOM content script maps inputs by label, placeholder, aria-tag, and surrounding DOM hierarchy. Executes 1-click synthetic input events in 0.12s.

Chrome • Edge • Brave V3
