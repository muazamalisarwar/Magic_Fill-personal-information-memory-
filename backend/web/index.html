Frequently Asked Questions

Everything you need to know about Magic Fill form learning and autofill.

How does Magic Fill learn new fields automatically?

When you finish filling an input on any website and blur or change it, Magic Fill analyzes the field's semantic category. If it's a reusable personal attribute (like LinkedIn URL, portfolio, or certification) that isn't already in your memory, a non-intrusive prompt appears asking if you want to save it with 1 click.

Does Magic Fill save my passwords, OTPs, or chat messages?

Never. Magic Fill enforces a strict 6-category classification system. Chat textareas (like ChatGPT or support chat), search bars, comments, passwords, OTPs, and payment credentials are automatically quarantined both on the client and server. They never trigger memory prompts and are never saved.

What happens when a website uses different labels for the same thing?

Magic Fill normalizes semantic equivalents. For example, "Mobile Number", "Cell Phone", and "Telephone" are mapped to your canonical phone attribute. If the value entered matches your saved phone, no duplicate is created. If you enter a new phone number, it asks whether you want to update your memory.

How does the Chrome extension connect securely?

You can connect using 1-Click Tab Sync or a short-lived, single-use authorization code (MF-XXXXXXXX). Your master password is never sent to or stored inside the extension.
